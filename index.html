1. Privacy Principles & Offline Commitment

NotNow Shell is a native desktop shell for Windows 11 designed with complete privacy by design. The application is engineered to operate 100% offline.

Zero Telemetry Commitment: NotNow Shell does not collect, log, track, or upload any user data, telemetry, analytics, or behavioral statistics to remote servers or third parties.

2. Code & Architecture Verification

The application is written in native C++17 and Win32/Direct2D:

  • No Networking Libraries: The codebase does not link against or call any Windows network libraries, including WinHTTP, WinINet, urlmon (URLDownloadToFile), or Winsock sockets (ws2_32.lib).
  • No Network Capabilities: The official Microsoft Store package (MSIX) declares only runFullTrust and intentionally omits the internetClient and internetClientServer capabilities.
  • Zero SDKs: No third-party analytical, crash-reporting, or advertising SDKs are included.

4. System Integrations

  • Wi-Fi Status: The quick settings flyout queries the local Windows Native Wi-Fi API (wlanapi.dll) solely to show available local SSIDs and toggle the adapter. No scan data leaves the device.
  • Web Search / Links: When choosing web search in launcher or clicking an external link, NotNow Shell calls Windows ShellExecuteW, handing the request over to your default web browser. NotNow Shell initiates no web requests itself.
  • Web search: The search query goes to the search engine you choose in Settings > Search and launch (Google by default; Bing, DuckDuckGo, Yandex or your own address). The query is sent only when you pick the web search row, and only through your browser.
  • Windows notifications: If the notification card is on ([notifications] systemToasts=1), NotNow Shell reads the notifications other apps show, read-only, from the Windows notification database on your PC, to show them near the panel. They are not sent anywhere. Turn it off in Settings > Icons and notifications.
  • Microphone level: The volume mixer shows the live level of your microphone only while the mixer window is open. Sound is not recorded or stored.
  • Screenshots: Screenshots you take with NotNow are saved only where you choose or copied to the clipboard.
  • Audio Mixer: Volume adjustments interact locally with Windows Core Audio sessions.

5. Uninstalling and Complete Removal

Microsoft Store version: uninstalling NotNow Shell in Windows Settings > Apps removes the program together with all its settings and histories. Before uninstalling you can keep your settings with Settings > About > Save settings to a file.

NotNow Shell — нативная оболочка рабочего стола для Windows 11, построенная на концепции абсолютной конфиденциальности (Privacy by Design). Приложение функционирует на 100% в офлайн-режиме.

Нулевая телеметрия: NotNow Shell не собирает, не отслеживает, не протоколирует и не отправляет пользовательские данные, телеметрию или статистику на удалённые серверы или сторонним организациям.

2. Архитектура и проверка исходного кода

Приложение написано на C++17, Win32 и Direct2D:

  • Отсутствие сетевых модулей: В исходном коде отсутствуют вызовы сетевых библиотек Windows: WinHTTP, WinINet, urlmon (URLDownloadToFile) и сокетов Winsock (ws2_32.lib).
  • Отсутствие сетевых прав в Microsoft Store: Пакет MSIX для Microsoft Store декларирует только стандартный запуск runFullTrust и не запрашивает разрешений internetClient или internetClientServer.
  • Без сторонних SDK: В коде нет аналитических сервисов, трекеров и рекламных библиотек.

4. Взаимодействие с системой

  • Wi-Fi сети: Шторка быстрых настроек опрашивает Windows Native Wi-Fi API (wlanapi.dll) только для отображения доступных сетей и переключения подключения. Данные сканирования не передаются вовне.
  • Веб-поиск и ссылки: При выборе поиска в сети лаунчер вызывает системную функцию ShellExecuteW, передавая URL вашему браузеру по умолчанию. NotNow Shell самостоятельных сетевых запросов не делает.
  • Веб-поиск: Запрос уходит в поисковую систему, которую вы выбрали в Настройках > Поиск и запуск (по умолчанию Google; также Bing, DuckDuckGo, Яндекс или свой адрес). Запрос отправляется только когда вы выбрали строку веб-поиска, и только через ваш браузер.
  • Уведомления Windows: Если включена карточка уведомлений ([notifications] systemToasts=1), NotNow Shell читает уведомления других программ — только чтение — из базы уведомлений Windows на вашем ПК, чтобы показать их у панели. Никуда они не передаются. Отключается в Настройках > Значки и уведомления.
  • Уровень микрофона: Микшер громкости показывает уровень микрофона только пока окно микшера открыто. Звук не записывается и не сохраняется.
  • Снимки экрана: Снимки экрана, сделанные в NotNow, сохраняются только туда, куда вы укажете, или копируются в буфер обмена.
  • Микшер громкости: Управление уровнем громкости приложений работает локально через Windows Core Audio.

5. Полное удаление

Версия из Microsoft Store: удаление NotNow Shell через Параметры Windows > Приложения удаляет программу вместе со всеми настройками и историями. Перед удалением настройки можно сохранить: Настройки > О программе > Сохранить настройки в файл.
